# Fantazone

Fantazone is the zero-server evolution of Fantasoccer: a React Native + Web application where persistent fantasy-football state is stored in GitHub repositories, automation is orchestrated through GitHub workflows, and real-time auctions use WebRTC.

> The repository is being bootstrapped from the existing `KeyserDSoze/Fantasoccer` product and its business rules. See `docs/` for the migration inventory and architecture decisions as they are added.
